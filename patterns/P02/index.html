03

Pointcut

Where the mechanism applies. All four dimensions belong to the proposed match, not just its vocabulary.

Context
Multiple model, tool, or batch tasks are authorized to run concurrently.
Trigger
A batch is dispatched or streamed.
Structure
Invocation identity, cancellation control, and result correlation.
Effect
Streamed or completed results are merged without losing or duplicating ownership.
04

Protected contract

The obligation that clients, operators, and auditors should be able to rely on.

Requires
The runtime exposes concurrency and a way to await or cancel outstanding work.
Ensures
Every accepted invocation is linked to its result or explicit failure.
Invariant
The harness does not declare completion while unreconciled work remains.
Violation
Partial failure and cancellation produce explicit terminal states and cleanup.

Negative control

Generic concurrency in an unrelated subsystem does not count.

05

Variation & lifecycle

The hot spot is admitted only where the protected semantics survive.

Permitted variation

Batch size, asyncio or promise scheduler, streaming reducer, and ordering policy.

Test obligation

Test one failure, cancellation, completion order, and concurrent side effects.

Evolution question

Did concurrency expand from tools to agents and preserve correlation?

06

Prompt + code design

An illustrative prompt and a small design sketch for the proposed contract. Names and APIs are invented; this is not a repository excerpt.

PROMPT SKETCH
Dispatch independent invocations concurrently. Give every invocation a stable identity, stream results as they arrive, and do not declare the batch complete until each invocation has a result, a failure, or an explicit cancellation record.
CODE DESIGN / PYTHON
async def run_batch(invocations, runtime):
    pending = {inv.id: asyncio.create_task(runtime.invoke(inv)) for inv in invocations}
    results = {}
    for finished in asyncio.as_completed(pending.values()):
        result = await finished
        results[result.invocation_id] = result
        yield result
    missing = set(pending) - set(results)
    if missing:
        raise BatchIncomplete(sorted(missing))

Illustrative design sketch. Correlation by invocation id is the contract; concurrency alone is not. This example is a teaching aid, not implementation evidence or a conformance claim.
