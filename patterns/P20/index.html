03

Pointcut

Where the mechanism applies. All four dimensions belong to the proposed match, not just its vocabulary.

Context
An attempt can be evaluated before a further attempt.
Trigger
The attempt fails or receives a critique.
Structure
Attempt record, feedback producer, revision input, and retry bound.
Effect
A revised attempt uses recorded feedback while preserving attempt lineage.
04

Protected contract

The obligation that clients, operators, and auditors should be able to rely on.

Requires
Failure evidence and remaining retry budget are available.
Ensures
Feedback is attached to the attempt that produced it and is visible to revision.
Invariant
Self-critique is not represented as independent verification.
Violation
Empty, contradictory, or exhausted feedback terminates or escalates.

Negative control

A static system prompt asking the model to reflect is not enough.

05

Variation & lifecycle

The hot spot is admitted only where the protected semantics survive.

Permitted variation

Self-critique, external evaluator, memory injection, and iterative refinement.

Test obligation

Test useful feedback, contradictory feedback, exhaustion, and repeated error.

Evolution question

Did reflection add independent evaluation and bounded convergence?

06

Prompt + code design

An illustrative prompt and a small design sketch for the proposed contract. Names and APIs are invented; this is not a repository excerpt.

PROMPT SKETCH
After a failed attempt, attach the failure evidence to that attempt and make it visible to the next revision. Stop when the retry budget is exhausted rather than retrying without new information.
CODE DESIGN / PYTHON
def revise(task, attempt, budget):
    if not budget.remaining:
        return Failed(task, attempt, reason="retry budget exhausted")
    feedback = evaluator.diagnose(attempt)
    next_prompt = task.prompt.with_feedback(
        attempt_id=attempt.id,
        feedback=feedback,
    )
    return attempt.run(next_prompt, budget.decrement())

Illustrative design sketch. Reflection is useful only when the feedback is linked to the attempt that produced it. This example is a teaching aid, not implementation evidence or a conformance claim.
